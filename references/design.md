# デザイン（Stitch「Civic Cyber Sentinel」を移植したもの）

Google Stitch で作ったデザインシステム「Civic Cyber Sentinel」の見た目を、Tailwind などを使わずに `assets/style.css` に移したもの。
文言・構成は `build.py` が出し、見た目は CSS だけで決まる。

## 色

| 用途 | 色 |
|---|---|
| 濃紺（ヘッダーのマーク・タブの選択・要点カード・表の見出し・CTA帯） | `#0B192C` |
| シアン（副題・目次の現在地・CTAボタン） | `#0E7490`（濃）／`#22D3EE`（明） |
| 地 | `#F8FAFC`、線 `#E2E8F0`、Q&Aの地 `#EFF4FF` |
| 「資料公表後の動き」 | アンバー `#F59E0B`／`#FFFBEB` |
| 読む人の札 | staff 青 `#EFF6FF`/`#1D4ED8`、vendor 緑 `#F0FDF4`/`#15803D`、exec 灰 `#F8FAFC`/`#334155` |

角丸は 4〜8px。フォントは Noto Sans JP（見出しもゴシック）。
色を変えるときは `style.css` 冒頭の `:root` と、末尾の「Stitch デザイン」ブロックの色を置き換える。

## ページの部品（上から）

1. ヘッダー：白地、濃紺の四角に盾マーク（`site.icon`）、`brand_sub` の札、サイト名、検索欄、CTAボタン
2. タブ：`groups[].tab` ごと。今いるグループが濃紺
3. パンくず帯（薄い灰）
4. 題名の部分（全幅）：原文の場所の札（濃紺）・読む人の札 → 題名（3段）→ 導入文 → ヒーロー帯（画像＋グループ名の札＋短い題名）→ 著者バー（顔・名前・公開/更新日・「原本（PDF）を開く」「目次へ」・CTA）
5. 2列：左＝このページの目次カード（スクロール追従・現在地がシアン）＋記事の目次＋左の列のリンク、右＝要点カード（濃紺）→ 節のカード
6. 節：番号の札＋見出し → Q/A の枠 → 原文引用（白いカード、本文は薄い灰） → 解説（左に濃紺の線、著者の顔） → ポイント → 確認ボックス（✓） → よくある疑問 → 関連語のチップ
7. 出典・参考資料（アコーディオン）→ 著者紹介 → 前後のページ
8. CTA帯（濃紺のカード）→ フッター（淡い青）

## スマホ（720px以下）

- タブ・パンくず帯・ヒーロー帯は出さない
- 検索・CTA・記事の目次・このページの情報はハンバーガーメニューにまとめる
- 節はカードをやめて普通の流れに。3列以上の表は、各セルに列名を付けたカード表示（`site.js`）
- 見出しは `jb()` で文節ごとに `<wbr>` を入れ、iPhone の Safari でも単語の途中で改行しない
- 1024px以下では、左の目次カードの代わりに本文の頭に目次を出す（「目次へ」ボタンも隠す）

## ヒーロー画像

`site.hero_image` に横長の画像（目安 1376×768、主題は中央より少し上）を指定すると全ページの題名の下に出る。
同じ画像が全ページで繰り返されるので、文字の入っていない抽象的な画像が向く。指定しなければ濃紺の格子模様の帯になる。
