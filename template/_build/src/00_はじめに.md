# 5分でわかる ハンドブックの要点

みらい市 防災ハンドブック（サンプル）は、家庭での備えと、災害が起きたときの家族の行動をまとめた資料です。このページでは、ハンドブック全体の要点と、どのページから読めばよいかを5分で整理します。

## 0-まとめ このページの要点

- 0-1 ハンドブックの中心は「日ごろの備え」です。備蓄、非常持出品、家族の連絡方法の3つを押さえます。

## 0-1 このハンドブックで何がわかるか

> この節が答える質問：みらい市 防災ハンドブックには何が書いてありますか？

### 解説

ハンドブックは、災害が起きる前に家庭でできることを中心にまとめています。まず「[1. 日ごろの備え](sonae.html)」から読むのがおすすめです。

### ポイント

- 備蓄は最低3日分、できれば1週間分。
- 非常持出品はリュックサックにまとめる。
- 家族の集合場所と連絡方法を決めておく。
