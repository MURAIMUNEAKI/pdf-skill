# 付録 用語集

防災ハンドブック（サンプル）に出てくる言葉を、わかりやすく解説しました。英字の用語を先に、続けて五十音順に並べています。

## ローリングストック（ろーりんぐすとっく）{rolling-stock}

ローリングストックは、普段食べている食料や飲料を少し多めに買い置きし、使った分を買い足して、常に一定量を備えておく方法です。

特別な非常食をしまい込むのと違い、賞味期限切れを防ぎやすく、食べ慣れた物を災害時にも食べられます。

関連語：災害用伝言ダイヤル

## 災害用伝言ダイヤル（さいがいようでんごんだいやる）{dengon-dial}

災害用伝言ダイヤルは、大きな災害で電話がつながりにくいときに、声の伝言を録音・再生できるサービスです。「171」に電話して使います。

決まった日に体験利用ができるので、家族で一度試しておくと、いざというときに迷いません。

関連語：ローリングストック
